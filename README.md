# checkautos-videos

1. Desde el teléfono, sube la nota de voz y las fotos/videos a una carpeta nueva `entrada/vidN/` (app de GitHub).
2. En la app de Claude → Code → sesión en la nube sobre este repositorio: escribe "edita entrada/vidN".
3. El video terminado aparece en `salida/`.

Las reglas del flujo están en CLAUDE.md.
